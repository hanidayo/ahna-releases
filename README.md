# 아나 (Ahna) 내려받기

> 경상도 말로 "아나~" — 옛다, 받아라. 툭 건네듯 주고받는 앱입니다.

**한국어** · [English](#english)

Windows · Mac · iPhone/iPad · Android 사이에서 파일과 글자(클립보드)를 주고받습니다.

| 기기 | 내려받기 | 설치 |
|---|---|---|
| Windows | [Ahna-Setup.exe](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-Setup.exe) | 내려받아 실행하면 설치됩니다. ‘Windows의 PC 보호’ 창이 뜨면 [추가 정보] → [실행] |
| Mac | [Ahna-Mac.zip](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-Mac.zip) | 압축을 풀고 아나를 응용 프로그램 폴더로 옮기세요. ‘확인되지 않은 개발자’ 경고가 뜨면 시스템 설정 › 개인정보 보호 및 보안 맨 아래의 [그래도 열기] |
| Android | [Ahna-Android.apk](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-Android.apk) | 내려받아 설치 (출처를 알 수 없는 앱 허용) |
| iPhone · iPad | [Ahna-iOS.ipa](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-iOS.ipa) | IPA 파일 (Sideloadly 등으로 설치) |

- 처음 실행하면 **초대 코드**를 묻습니다. 아나를 알려 준 사람에게 받으세요.
- 등록한 기기끼리는 어디서나, 등록하지 않은 사람과는 **근처 기기(Bluetooth)** 로, 앱이 없는 사람과는 **QR(브라우저)** 로 주고받습니다.
- 설치한 뒤에는 앱이 스스로 업데이트를 알려 줍니다. 지난 버전은 [Releases](https://github.com/hanidayo/ahna-releases/releases)에 있습니다.

## English

Ahna ("here, catch!" in the Gyeongsang dialect of Korean) sends files and clipboard text between Windows, Mac, iPhone/iPad and Android.

| Device | Download | Install |
|---|---|---|
| Windows | [Ahna-Setup.exe](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-Setup.exe) | Run it. If SmartScreen appears: *More info* → *Run anyway* |
| Mac | [Ahna-Mac.zip](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-Mac.zip) | Unzip and move Ahna to Applications; if blocked, *Open Anyway* in System Settings › Privacy & Security |
| Android | [Ahna-Android.apk](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-Android.apk) | Install the APK (allow unknown sources) |
| iPhone · iPad | [Ahna-iOS.ipa](https://github.com/hanidayo/ahna-releases/releases/latest/download/Ahna-iOS.ipa) | Sideload the IPA (e.g. Sideloadly) |

On first launch the app asks for an **invite code** — get it from the person who shared Ahna with you. Registered devices exchange files from anywhere; people nearby are reached over Bluetooth; people without the app use a QR code in the browser.
